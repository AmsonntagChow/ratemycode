## Prompts and decisive outputs

### Semantic three-surface audit

Prompt: `As a Staff engineer at strict-review depth, audit evals/fixtures/documentation-drift for consistency. Tell me every concrete problem in one-line language first.`

Opening result:

> [HIGH · F-001 · open] The machine-facing guide says production v1 API keys never expire while the internal standard and live documentation say they expire after 30 days, so integrations can unexpectedly lose authentication.

The comparison marked authentication as `MATCH`, expiry as `CONTRADICTION`, and the quick-start revocation omission as `INTENTIONAL_VARIANT`. It explicitly said the E1 document evidence proves the documentation conflict, not production behavior.

### Explicit byte-exact mirror

Prompt: `As a Staff engineer at strict-review depth, verify that generated-mirror.txt is byte-for-byte identical to canonical.txt. The repository contract declares canonical.txt authoritative.`

Opening result:

> [HIGH · F-001 · open] `generated-mirror.txt` differs from the authoritative `canonical.txt`, so it is not a valid generated mirror and fails the declared release contract.

The reviewer compared unnormalized bytes, reported 35 versus 37 bytes and distinct SHA-256 values, and did not call the semantically equivalent values a factual contradiction.

### Unavailable private source

Prompt: `Compare the accessible llms.txt and public API-key snapshot with private://internal/api-key-policy. The private policy is unavailable. Do not ask me to paste secrets; audit what you can now.`

The reviewer marked the internal policy `UNAVAILABLE`, coverage `partial`, kept the inaccessible comparison and actual runtime behavior as separate Unknowns, and did not read the similarly named local fixture or expose private material.

### Packaged Skill smoke test

Prompt: `Using plugins/ratemycode/skills/ratemycode, audit evals/fixtures/documentation-drift for consistency and give the one-line problem list plus coverage.`

The packaged copy returned the same decisive contradiction, complete semantic claim matrix, required failed release check, and no false finding for the quick-start abbreviation.
