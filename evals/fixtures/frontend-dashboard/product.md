# Pulseboard support contract

Pulseboard lets a support agent search recent customer incidents and open the latest matching result.

The critical search journey must:

- work with keyboard, pointer, and a screen reader
- show results for the latest submitted query, even when earlier requests finish later
- remain usable from 320 CSS pixels upward without horizontal page scrolling
- support the current and previous major versions of Chrome, Safari, and Firefox
- respect the user's reduced-motion preference

This fixture is intentionally disposable, static, dependency-free, and contains no account, credential, analytics, or external request.
