# Privacy Policy

Effective date: July 28, 2026

RateMyCode is a skills-only plugin distributed as source files. It does not operate a hosted service, create an account, run its own network endpoint, maintain a database, or include developer-operated telemetry.

When a user asks an AI agent to review a product, the agent may inspect files, URLs, logs, test data, or other artifacts that the user places in scope. That processing is performed by the user's AI provider and local or hosted execution environment, subject to their settings and privacy terms. RateMyCode does not separately receive or store those artifacts.

If the user asks to persist an audit or authorizes a fix loop, the host agent may create local JSON ledger snapshots and generated Markdown reports in the chosen workspace. Those files can contain finding details, evidence locations, change references, reviewer identifiers, and copied user authorization or risk-acceptance statements. Snapshot continuity intentionally preserves prior evidence and record identities, so users should avoid including secrets or unnecessary personal data and should manage retention for the complete snapshot chain, not only its newest report.

The plugin contains no advertising, analytics SDK, authentication system, or sale of personal data. If a user directs the host agent to access a third-party service, that service's own privacy terms apply.

Questions or privacy reports can be filed through [GitHub Issues](https://github.com/AmsonntagChow/ratemycode/issues). Material changes to this policy will be published in this repository with an updated effective date.
